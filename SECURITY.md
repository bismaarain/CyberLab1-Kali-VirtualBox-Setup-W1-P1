# Security Policy

This repository documents an educational cybersecurity lab. It does not authorize testing against systems belonging to other people or organizations.

## Safe Use

- Perform exercises only on systems you own or have explicit permission to test.
- Keep intentionally vulnerable virtual machines isolated from untrusted networks.
- Do not publish credentials, private keys, access tokens, personal data, or sensitive network information.
- Review terminal output and screenshots before committing them.
- Use official software sources and keep the host system protected.

## Reporting a Concern

If repository content exposes sensitive information, remove it from the repository and review the relevant Git history and credentials. Rotate any exposed secrets immediately.
