# Contributing

Thank you for helping improve this learning repository.

## Documentation Guidelines

- Use clear headings and concise explanations.
- Verify technical steps in the lab before describing them as completed.
- Keep commands in fenced code blocks.
- Include expected results only when they have been checked.
- Do not add credentials, personal information, or sensitive network details.

## Screenshots

- Use screenshots captured from the actual lab.
- Store them in `screenshots/`.
- Use descriptive filenames.
- Check images for private or sensitive information before committing.
