# Lab Validation Checklist

Update this checklist only after each item has been checked.

- [ ] Kali Linux VM boots successfully.
- [ ] VirtualBox adapter is enabled.
- [ ] Selected network mode is documented.
- [ ] Network interfaces and IP configuration are inspected.
- [ ] Routing table is reviewed.
- [ ] DNS resolver configuration is reviewed.
- [ ] Relevant connectivity checks are recorded.
- [ ] A baseline snapshot is created if required.
- [ ] Screenshots are genuine and reviewed for sensitive information.
- [ ] Lab notes reflect the actual configuration and results.
