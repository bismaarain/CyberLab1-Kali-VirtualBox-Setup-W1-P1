# Kali Linux Virtual Machine - Installation Guide

This guide is a planning checklist. Follow the official installation instructions for the versions you choose.

## Prerequisites

- A computer with hardware virtualization support.
- Oracle VirtualBox installed from its official source.
- A Kali Linux installer image from the official Kali Linux website.
- Adequate memory and disk space.

## Workflow

1. Download the appropriate Kali Linux image from the official source.
2. Create a new virtual machine in VirtualBox, or import a supported prebuilt image.
3. Assign VM resources appropriate for the host computer.
4. Attach the installer image if performing a manual installation.
5. Complete the installation using the on-screen instructions.
6. Boot the VM and verify that the desktop or login screen loads.
7. Record actual VM settings and software versions in `../LAB-NOTES.md`.

## Verification

Do not mark installation complete until the VM has successfully booted. Add screenshots captured from your own environment to `../screenshots/`.
